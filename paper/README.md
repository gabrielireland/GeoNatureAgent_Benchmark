# Paper

Two versions of the paper live here, plus shared figure/data tooling.

| Path | What |
|------|------|
| **`SIGSPATIAL_2026/`** | The **ACM SIGSPATIAL 2026 submission** (`acmart`, `sigconf`). Self-contained: its own `acmart.cls`, `references.bib`, and `figures/`. This is the canonical venue version. |
| **`arxiv/`** | The **arXiv variant** (`\documentclass{article}`, `plainnat`). Uses the shared `../figures/` and its own `references.bib`. **Not yet submitted** — target: after SIGSPATIAL acceptance (notification 2026-08-05), per `PENDING.md`. |
| `figures/` | Shared figures, generated by `generate_figures.py` (the arXiv version links here via `../figures/`; the SIGSPATIAL version keeps its own copy for a self-contained submission tarball). |
| `final_results/` | Source-of-truth result CSVs (`leaderboard.csv`, `per_category.csv`, `per_case.csv`) + `sources.yaml`. Every number in both papers derives from these. |
| `generate_figures.py` | Regenerates `figures/` from `final_results/`. |

## Building

```bash
# Figures (shared) — run from paper/
python generate_figures.py

# SIGSPATIAL version
cd SIGSPATIAL_2026
pdflatex geonatureagent_benchmark.tex && bibtex geonatureagent_benchmark && \
  pdflatex geonatureagent_benchmark.tex && pdflatex geonatureagent_benchmark.tex

# arXiv version
cd arxiv
pdflatex geonatureagent_benchmark.tex && bibtex geonatureagent_benchmark && \
  pdflatex geonatureagent_benchmark.tex && pdflatex geonatureagent_benchmark.tex
```

## Keeping them in sync
Both versions report the same results. When `final_results/` changes: re-run
`generate_figures.py`, then update the leaderboard table cells in **both** `.tex` files.
Content should stay aligned; only formatting (ACM `acmart` vs. plain `article`) differs.
